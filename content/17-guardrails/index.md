Guardrails are checks in code that run at fixed points of every agent run: before the agent starts, around each model and tool call, and before the answer goes back. This module starts with the ideas (what to check, where, and with rules or with a model), then uses LangChain's built-in middleware to redact personal data and to require a person's approval, writes its own input and output checks as middleware classes, and finally stacks them into a healthcare assistant, ending with the assistant in one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
