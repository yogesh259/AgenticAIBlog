The parts that turn a chatbot graph into an agent. The module starts with the state itself: the same graph over a `TypedDict`, a dataclass and a Pydantic model, and what each one checks. Then a model gets tools inside a graph: `ToolNode` runs what the model asks for and `tools_condition` routes to it, first as a router that decides once, with one tool and then with search tools for arXiv, Wikipedia and the web. One edge back from the tools to the model turns the router into a ReAct agent that acts, observes and reasons until it can answer. A checkpointer gives the agent a memory per conversation thread, and streaming shows each step and token as it happens, ending with the whole agent in one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
