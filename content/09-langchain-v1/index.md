LangChain 1.x is built around agents. This module assembles one from its parts: a chat model created for any provider with one function, the messages it reads and writes, tools it can ask for, the loop that `create_agent` runs, answers in a schema you define, and middleware that summarises long conversations or pauses for a person's approval before a risky tool runs. Lesson 9.8, An agent in one script, puts everything together in one file with Gemini. The agent loop itself is explained in [lesson 8.1](lesson:8.1); the classic chains of modules 06 and 07 still work alongside. Run the notebook cells in order, and try each practice task before you open its solution.
