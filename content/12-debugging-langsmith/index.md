How to see inside an agent. The module starts with tracing: what a trace of the tool-calling agent records, how a few environment variables send every run to LangSmith, how to name, tag and group runs, find the step that failed, keep private data out of traces, and turn the same records into evaluations. Then LangGraph Studio: two files and `langgraph dev` serve the agent on your machine, and the browser draws it, runs it, pauses it before a tool, lets you edit the tool call and fork the run, ending with the agent in one file with Gemini. Try each practice task before you open its solution.
