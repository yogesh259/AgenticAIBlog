Pausing a graph so a person can approve, correct or redirect it, and going back through its saved steps. The module starts with breakpoints: compiled with `interrupt_before`, the arithmetic agent stops before the model with its state saved, `get_state` shows where it stopped, and `None` lets it continue. Then the saved state is edited with `update_state`, which works through the reducers and can hand the run a person's typed input as a node's output with `as_node`. The `interrupt` function moves the question and the answer inside a node, which is how a review step approves, edits or rejects the model's tool calls. Time travel replays a run from any checkpoint or forks it with changed state, and the module ends with an approval agent in one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
