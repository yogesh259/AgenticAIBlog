Retrieval without embeddings or a vector store. Instead of cutting a document into chunks and searching for the ones that look most like a question, vectorless RAG keeps the document's own structure as a tree, a table of contents with page numbers and summaries, and lets a model reason its way to the sections that answer the question, the way an expert reads a long report. The module starts with the idea: why similarity isn't relevance, how the tree is built, how the search works, and when it beats vector RAG. Then it indexes "Attention Is All You Need", the paper module 06 searched with vectors, with PageIndex, in its cloud or on your own machine, and builds the retrieval half on top: a tree search, the sections it picks, an answer that cites them, domain rules in the prompt, and PageIndex's own chat, ending with the pipeline in one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
