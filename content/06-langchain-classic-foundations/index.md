Chat models from OpenAI, Google and Ollama; then retrieval-augmented generation (RAG), what it is and why agents rely on it, and each of its steps in turn: loading documents, cutting them into chunks, turning chunks into vectors, and searching them in FAISS and Chroma. Lesson 6.8, A Simple RAG App, puts every step in one script with Gemini, with the same app built cell by cell behind Explain boxes. The code uses LangChain's classic chains; [module 09](module:09) covers the newer agent API. Run the notebook cells in order, and try each practice task before you open its solution.
