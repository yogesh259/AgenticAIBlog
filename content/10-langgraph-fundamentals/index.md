LangGraph runs an LLM application as a graph: steps that share one state, and edges that decide which step runs next, loops included. This module starts with the ideas (what a graph is made of, how a run proceeds, and when a graph beats a chain or `create_agent`), then builds a first graph with no model at all, then a chatbot whose conversation lives in the state, ending with the chatbot in one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
