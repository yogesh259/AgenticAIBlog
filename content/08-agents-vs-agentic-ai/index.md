What makes a program an AI agent: a model that decides the next step, tools it asks the application to run, memory, and the loop that ties them together. Then agentic AI, where several agents split a larger goal, check one another's work and hand the important decisions to people, and the question behind every design in the modules that follow: how much of the control flow should the model own? Both lessons are concepts with interview questions; their practice tasks build the agent loop and a small multi-agent pipeline in plain Python, with no model or API key needed.
