The five workflow patterns as LangGraph graphs: fixed code paths with model calls inside. Prompt chaining runs one call after another with a check between steps; parallelization runs independent calls at the same time and merges them; routing classifies the input and sends it to the step built for it; orchestrator-worker lets a model plan the subtasks at run time and starts one worker per subtask with `Send`; evaluator-optimizer loops a writer and a grader until the work passes. Each lesson builds its pattern on a small story, joke or report task, explains how LangGraph runs it, and shows what goes wrong and how to bound it; the last lesson compares the five and combines two of them in a report writer, one script with Gemini. Run the notebook cells in order, and try each practice task before you open its solution.
