RAG as a LangGraph graph, with a model deciding around the search instead of a fixed retrieve-then-answer chain. The first lesson compares three designs and the research behind them: agentic RAG, where a model with retriever tools decides whether and where to search; corrective RAG, which grades every retrieved chunk and turns to a web search when the chunks fail; and adaptive RAG, which routes each question to the right source and checks its own answer before returning it. The next three lessons build each design over real web pages, show what their runs did and where their loops never end, and the last one combines them in a single script with Gemini, with limits on every retry. Run the notebook cells in order, and try each practice task before you open its solution.
